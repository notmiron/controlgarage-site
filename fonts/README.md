# Self-hosted fonts

The WOFF2 files in this directory were downloaded unmodified from the Google
Fonts CSS API on 2026-09-13. They contain the `latin` and `latin-ext` subsets
for the families and weights used by the site:

- Inter, variable weight 300–700 (`inter/v20`)
- Bebas Neue, weight 400 (`bebasneue/v16`)
- Dancing Script, weight 700 (`dancingscript/v29`)

Upstream stylesheet request:

`https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Dancing+Script:wght@700&family=Inter:wght@300;400;500;600;700&display=swap`

The corresponding SIL Open Font License texts were downloaded from the
official [`google/fonts`](https://github.com/google/fonts) repository and are
stored in `licenses/`.
